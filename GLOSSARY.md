# Quillmit

Quillmit writes commit messages and pull requests with a local AI CLI, so people
and AI agents hand that work to one tool instead of writing it themselves.

## Language

**Agent Guide**:
Quillmit's short usage guide for AI agents, linked from each Global Instructions File.
_Avoid_: agent instructions, Quillmit block

**Global Instructions File**:
An AI agent's user-wide instructions file, such as Claude Code's `CLAUDE.md` or Codex's `AGENTS.md`.
_Avoid_: global prompt, agent config
